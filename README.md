# PocketDeck
App para encender/apagar un servidor PocketMine en Termux.
1. En Termux: `bash setup_termux.sh` (una vez).
2. Compila: sube esta carpeta a un repo de GitHub y descarga el APK desde Actions > Build APK,
   o abre la carpeta en Android Studio.
3. Instala el APK, concede el permiso de Termux y toca el botón.
